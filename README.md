# QM Pixel Studio

Browser controller for "QM-LED" Bluetooth pixel panels (the QMPIXEL app protocol).

Open: https://bayradberry.github.io/qm-pixel-studio/

- Mac/Windows/Android: Chrome or Edge
- iPhone/iPad: the Bluefy – Web BLE Browser app (Safari has no Web Bluetooth)

Pixel fonts: Spleen by Frederic Cambus (BSD 2-Clause, see SPLEEN-FONT-LICENSE.txt).
